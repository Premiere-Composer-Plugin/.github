## 🚀 Introduction
Premiere Composer for Windows is a plugin that extends Adobe Premiere Pro with a curated library of drop-in animations, so editors can spend less time keyframing and more time telling the story. Rather than opening a separate motion app, you work from a single docked panel that holds animated titles, transitions, and sound effects ready to drag onto any clip. As a Premiere Composer plugin, it fits naturally into the editing workflow and keeps every element a click away. It is a practical, time-saving companion for anyone finishing videos in Premiere Pro.

## ✨ Highlights

### Motion & Type
- **Animated text presets** that build titles, captions, and lower thirds with automatic in-and-out animation.
- **Transition presets** for glitch, zoom, pan, and light-leak moves that snap between clips.

### Sound & Growth
- **Bundled sound effects** so your visual hits land with matching whooshes and impacts.
- **A free Starter Pack** on install, with optional paid content packs and Pro features when you want more.

## 💻 System Specs

**Minimum**
- OS: Windows 10 64-bit
- Host application: A supported version of Adobe Premiere Pro
- Processor: A modern 64-bit multi-core processor
- Memory: The RAM recommended for your Premiere Pro version
- Storage: Space for the plugin and the included Starter Pack

**Recommended**
- OS: Windows 11 64-bit
- Host application: The current release of Adobe Premiere Pro
- Processor: A recent high-performance multi-core processor
- Memory: More RAM than the Premiere Pro minimum for smoother previews
- Storage: Extra room for optional content packs

## 📥 How to Install
1. Use the **Download** button above to get the latest Premiere Composer package for Windows.

## 🎯 Getting Up and Running
1. Open Adobe Premiere Pro and load a project or sequence.
2. Show the Premiere Composer panel through the Window menu's Extensions list.
3. Preview presets across the text, transition, and sound categories.
4. Drag the preset you want onto a clip, then fine-tune it with the panel's controls.

## ❓ Common Questions
**Is Premiere Composer free?**
Yes. The Premiere Composer plugin is free to download and install and includes a free Starter Pack. For a larger collection you can add optional content packs and Pro features from Mister Horse.

**Which versions of Windows are supported?**
